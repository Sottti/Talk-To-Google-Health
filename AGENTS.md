# Talk-To-Google-Health

## Issues and pull requests

Follow the shared [contribution guide](https://github.com/Sottti/.github/blob/develop/CONTRIBUTING.md)
in `Sottti/.github` on `develop`. Read it before drafting an issue or pull request
title or body, and before merging a pull request: it sets the title rules, the
templates and the merge requirements, including the local peer review every pull
request needs before it merges. If it can't be read, say so instead of assuming a
local copy is current.
